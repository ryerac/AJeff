# Image plugin

Apply the **Image** preset to a display button, then use **Icon → Library…** or
**Upload Icon…** to choose its artwork. Existing static artwork is retained when
applying the preset. Pressing the button does nothing.

Images are copied into AJeff's local icon storage and use the existing resize and
crop behaviour. They work with scenes, copy/paste, brightness, and display sleep.

Uploads accept PNG, JPEG, BMP, GIF, and TIFF. GIF files are imported as a still
image and saved as JPEG; animated GIF playback is not supported.
